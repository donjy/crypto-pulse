# Crypto Pulse · 实时行情 + 顺大逆小 + 暴涨趋势做多榜 + 拉升后回落做空榜 + 关键价位 + 宏观 + X 情绪

纯前端单文件页面（React 18 + Tailwind CDN），暗色风格。支持 Binance / OKX 切换；配色默认「红涨绿跌」，可一键切到「绿涨红跌」。

线上页面：https://donjy.github.io/crypto-pulse/

## 运行
```bash
cd "Crypto Pulse"
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/index.html
```
请通过 http 打开，不要直接双击用 file:// 打开，因为页面需要加载同目录下的 `signals.js`、`levels.js` 和 `snapshot.js`。所有接口都是公开接口，不需要 API Key。

小技巧：
- `?plat=okx` 直接以 OKX 数据打开（默认 Binance）。
- `#/BTCUSDT`（OKX 为 `#/BTC-USDT-SWAP`）直接打开该币种详情，链接可分享。

## 顺大逆小信号规则（`signals.js`）
- **扫描范围**：24h 成交额前 80 的 USDT 永续（可选 40/80/120），每 3 分钟扫描一次。
- **做多条件**：
  - 1h、4h、1d 各自最近 N 根**已收盘** K 线（默认 N=2）全部收阳，且这几根的区间涨幅 > 0。
  - 同时，最近 K 根已收盘 15m K 线（默认 K=3，可在 2–5 之间调）全部收阴。
- **做空（可选）**：条件完全镜像，即大周期全部收阴、15m 连续收阳。
- **评分**：
  - score = 三个大周期区间涨幅之和 + 1.5 × min(15m 回调深度, 5%) + max(0, 45−RSI15m) × 0.3 + min(1h 量能倍数, 3)。
  - 1h 量能倍数 = 最近一根已收盘 1h K 线的成交额 ÷ 此前 24 根的平均值。
- **提醒**：点击「开启提醒」后，浏览器会请求通知权限。有新币种上榜时会弹出通知、播放提示音并高亮该行。
- 验证命令：`node test_signals.js binance`（或 `okx`）会用真实接口完整扫描一次。

## 暴涨趋势 · 做多开单榜（`trend.js`）
思路：涨幅榜上的币只有两种结局——继续涨，或者情绪到顶后暴跌。这个榜只做「继续涨」那一段：**1h 确认趋势 → 15m 回调找分歧 → 结构位止损 → 量价决定止盈方式**。

- **股票池**：24h 涨幅榜前 N（20/30/50 可选），且 24h 涨幅 ≥ 阈值（5/10/20/30% 可选）。每次扫描 3 个周期（15m ×96、1h ×200、4h ×60），每 3 分钟刷新。
- **拉升阶段**：以近 168 根 1h 的最低点为拉升起点，算出「已经拉了多久、累计涨了多少、距高点回落多少」，分成启动 / 主升 / 高位 / 末段 / 回撤。回撤阶段直接不参与。
- **入场（做多）**：
  - 1h 近 5 根 ≥3 根阳线，且区间涨幅 > 1.2%，价格在 1h EMA20 上方（大阳趋势）。
  - 15m 从最近高点回落 ≥0.35 ATR、≤4 ATR（且不超过 7%），回调段至少 1 根阴线——这就是「分歧」。
  - 入场区间取回调低点 / 15m EMA20 附近到现价上方 0.05 ATR；区间整体在现价下方时标注「等回踩」，包含现价时标注「现价可进」。
- **止损**：跌破 1h 近 6 根 K 线的最低点再留 0.3 ATR 缓冲即离场；1h 近 2 根最低点是减仓警示；**4h 近 3 根最低点是最后防线**，跌破说明整段拉升失效。单笔风险 > 8% 直接不入选，> 6% 标风险提示。
- **止盈（两种）**：
  - 保守：回调放量、或 1h 放量但斜率放缓 / 上影线变长 → 到 1.5R（t1）先减仓。
  - 激进：回调缩量、价格仍沿 15m 均线上行 → 持有到 3.5R（t2），并用 15m 前低 / EMA20 移动止损。
- **杠杆与强平**：逐仓近似 `强平价 ≈ 入场价 × (1 − 1/杠杆 + 0.5%)`；按止损距离反推「建议杠杆上限」，止损距离 > 强平距离 × 0.65 时标 ⚠ 提示降杠杆。
- **状态**：`可入场`（趋势 + 回调 + 风险都满足）、`等回调`（趋势成立但暂未回调）、`不参与`（回撤 / 破位 / 趋势不成立）。表格行悬停可看完整依据，点「详情」看该币的关键价位。

验证命令：`node test_trend.js binance 10` 或 `node test_trend.js okx 10`（用真实涨幅榜跑一遍，并断言止损 < 入场 < 保守目标 < 激进目标、强平与杠杆安全等）。

⚠ 该榜是机械规则，不含手续费、滑点、资金费率成本；涨幅榜末端行情变化极快，务必自己复核。

## 拉升后回落 · 做空开单榜（`short.js`）
对应《币安永续合约「拉升后回落」做空策略》：不赌「涨多了必跌」，而是**先确认拉升结束、结构破坏，再等反抽失败做空**。数据固定取币安 USDⓈ-M（页面切到 OKX 也不影响这个榜）。

- **Step 1 候选池**：24h 成交额前 N（60/90/120），且过去 48h 内任意时刻的滚动 24h 涨幅 ≥ 阈值（20/30/50%）。用 1h K 线回算，避开日界线；同时算出 `peak / base / pump% / 回吐比例`。
- **Step 2 状态机**（每行只落一个状态）：
  - `PUMPING 拉升中`：还在创新高或回吐 <3% → 排除；
  - `TOPPING 顶部衰竭`：回吐 3–10%，或结构还没破坏 → 观察；
  - `BREAKDOWN 破位`：跌破 1h 结构且 1h 收在 EMA20 下方；
  - `RETEST 反抽失败`：破位后反抽 EMA20 / VWAP / 0.382 回撤受阻（最佳入场）；
  - `DUMPED 跌过头`：回吐 >60% → 不追。
- **Step 3 确认证据**：4h 收在 EMA20 下方且 EMA20 拐头 / 2 根 4h 阴线累计 ≥1.5 ATR；1h 高点低点下移、跌破 EMA20；15m EMA20 < EMA50 且价格在 VWAP 下方；峰值长上影 + 天量；RSI 顶背离；OI 自峰值回落；资金费率从峰值回落；主动买入占比 <50%。
- **Step 4 交易计划**：入场取 EMA20(1h) / VWAP / 0.382 回撤中最近的反抽位（标注「等反抽」或「现价/破位」）；止损放最近 3 根 1h 高点 + 0.5 ATR(1h)；TP1/TP2 取**尚未回吐到**的下一档斐波那契（0.382→0.5→0.618→0.786→起涨平台），RR <1.8 或止损距离 >10% 不入选。
- **一票否决**：成交额 <2000 万、上线 <14 天、4h 仍在创新高、回吐 >60%、资金费率 ≤ −0.05%（空头拥挤）、BTC 1h 强势拉升。
- **评分（100）**：拉升强度 10 + 顶部衰竭 20 + 趋势转向 25 + 衍生品 20 + 入场质量 15 + 流动性与惩罚 10；带否决的分数封顶 45。
- **仓位**：按文档建议单笔风险 ≤ 账户 0.5–1%、杠杆 ≤3x、逐仓；按止损距离反推仓位，不要满仓。

验证命令：`node test_short.js 30 60`（扫描币安真实成交额前 60，打印候选池、状态、评分、入场/止损/TP 与一票否决，并断言做空方向的价格关系）。

⚠ 该榜依赖币安公开接口，属于机械规则；涨幅榜末端噪音大，务必先回测、小仓位验证。不构成投资建议。

## 关键价位与入场建议（`levels.js`）
详情抽屉里的「关键价位 · 支撑 / 阻力」对 5m / 15m / 1h / 4h / 1d 分别计算，数据是交易所公开 K 线与订单簿（一手数据，非第三方聚合），打开时拉取一次、之后每 60 秒刷新：

1. **成交量分布**：把每根 K 线的成交额按最高/最低价摊到 30 个价格格子，得到 POC（成交最密集价位）、70% 价值区（VAH/VAL）和成交量密集区（HVN）。同一根 K 线内用收盘价在区间中的位置拆分主动买/主动卖，用来判断某个价位是买盘还是卖盘更积极。
2. **摆动高低点**：分形法找 swing high/low，按 0.1%–0.8%（随 ATR 自适应）聚类成价位，触碰次数越多、成交量占比越大，强度分越高（同一周期内相对打分 5–97）。
3. **跨周期共振**：把 5 个周期的价位按 0.35% 带宽合并，≥2 个周期同时出现的标为共振位，周期越多强度加成越高。
4. **盘口大单墙**：订单簿近 ±3% 内的挂单按 0.12% 价格桶聚合成 USD 金额，列出买/卖各前 3 档，并给出买卖失衡比例。
5. **入场建议**：用 1d/4h/1h/15m/5m 的趋势（EMA20 vs EMA50 + 价格位置，权重 3/2/1.5/1/0.5）、资金费率（极端时反向修正）和盘口失衡算方向；再做多/做空分别取最近支撑或阻力作为入场带，止损放在结构外侧（至少 1.2×15m ATR 或 0.35% 缓冲），目标取对侧价位，输出盈亏比与失效条件。

验证命令：`node test_levels.js binance BTCUSDT` 或 `node test_levels.js okx BTC-USDT-SWAP`（会打印各周期支撑阻力、共振位、盘口墙和入场建议，并对结果做一致性断言）。

⚠ 所有价位与建议都是按固定规则的机械计算，不含手续费、滑点与资金费率成本，**仅供参考，不构成投资建议**。
